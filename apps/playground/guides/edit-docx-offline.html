Edit Word documents offline, without uploading them

Open a .docx file on your own computer, change the text and formatting, and save it back. InjOffice keeps the rest of the file as it was, and nothing leaves your machine.

Verified with InjOffice 0.1.15.

Why offline

Online converters and editors need a copy of your document on their servers. InjOffice opens the file from your disk and saves it there. The editor itself works without a network connection; the only thing it contacts on its own is GitHub, to check for app updates, and you can turn that off.

Steps

  1. Install InjOffice for macOS, Windows or Linux.
  2. Open the document with File, Open (Ctrl+O, or ⌘O on a Mac), or pick it from the recent files on the start page.
  3. Edit the text by clicking into the page and typing. Use the ribbon, or the toolbar that appears over selected text, for formatting such as bold and italic, paragraphs, hyperlinks, tables and PNG or JPEG images. Find and replace is in the ribbon.
  4. Save with Ctrl+S (⌘S). Save As (Ctrl+Shift+S) writes a copy under a new name. To share a fixed layout, use File, Export, Export PDF.

What happens to the rest of the file

A Word file is a package of many parts: text, styles, settings, images and more. InjOffice changes the parts your edit touches and keeps the others as they were, instead of rebuilding the whole file from its own copy. Features it does not edit are left in place rather than dropped.

If InjOffice closes unexpectedly

Unsaved work is journaled while you edit. The next time you start InjOffice, the start page offers to recover it.

Limits today

  • The on-screen page flows like a web page. Exact page layout comes from Export PDF, the path meant to match a printed page.
  • Tracked changes cannot be edited, and rich text cannot be restructured freely.
  • Macros in .docm files are never run.
  • Password-protected documents do not open: remove the password in the app that created the file first.
  • Older .doc files and OpenDocument .odt files are not opened.

Commands the engine cannot perform on a particular file are shown disabled with the reason, rather than failing silently. See compatibility for every format.
