Open and edit XLSX files without Excel

View and change an Excel workbook on your own computer: cell values, formulas and formatting. InjOffice is free, works offline, and keeps the parts of the workbook you did not touch.

Verified with InjOffice 0.1.15.

Steps

  1. Install InjOffice for macOS, Windows or Linux.
  2. Open the workbook with File, Open (Ctrl+O, or ⌘O on a Mac). It opens in a worksheet grid with a formula bar.
  3. Edit cells: select a cell and type a value, or a formula starting with =. Formulas are calculated on your computer. Copy and paste work across the grid.
  4. Format with the ribbon: supported cell styles, row heights and column widths.
  5. Save with Ctrl+S (⌘S), or Save As for a copy.

CSV and TSV

To bring in plain data, use File, Import CSV / TSV. To hand a sheet to another tool, use File, Export, Export selected sheet CSV / TSV; fields are written as literal text, or as the formula source.

What happens to the rest of the workbook

An .xlsx file holds many parts: sheets, styles, shared strings, charts and more. InjOffice writes the cells and properties you changed into the original file and keeps the other parts as they were, rather than regenerating the workbook.

Limits today

  • Structural edits such as inserting rows or columns are not available yet.
  • Only supported styles can be changed; other formatting is kept but not edited.
  • Binary .xls and .xlsb files and OpenDocument .ods files are not opened.
  • Password-protected workbooks do not open: remove the password in the app that created the file first.
  • The function reference lists the formulas the engine knows.

Commands the engine cannot perform on a particular file are shown disabled with the reason. See compatibility for every format.
