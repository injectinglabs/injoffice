Compatibility

What InjOffice opens, what it can change in each format today, and what it cannot.

Applies to InjOffice 0.1.15 and the current libraries.

Files the desktop app opens

FormatOpensExport
Word.docx, .docm (macros are never run)PDF
Excel.xlsx; CSV and TSV importSelected sheet as CSV or TSV
PowerPoint.pptxSlide as SVG
PDF.pdfSelected pages

Not opened: Word, Excel and PowerPoint 97–2003 binary files, .xlsb, and OpenDocument files, so their bytes are never rewritten. Password-protected files are refused; remove the password in the app that created them first.

What each format can change today

FormatCan changeNot yet
ExcelCell values and formulas, supported styles, row heights and column widthsInserting sheets, rows or columns and other structural edits
WordText replaced in place, with supported formattingRestructuring rich text freely, editing tracked changes, exact page layout
PowerPointSlide text and shape propertiesInserting or removing imported slides; editing pictures, charts, tables, groups and animations
PDFPage operations: rotate, crop, resize, reorder, insert and deleteGeneral text rewriting, OCR and redaction through the agent adapter

How files are kept

The original file stays the authority. InjOffice writes the changes it makes into that file and keeps the parts it did not change. Being able to display something does not mean it can be edited: some content is shown but kept read-only, and commands that would need to change it are disabled.

Layout

The document view flows on screen; page layout is a separate path, used for PDF export.

For developers

The libraries publish the same limits per operation, and every engine advertises which operations a given file supports. See the support and limitations page in the docs.

Report a file that misbehaves

Open an issue on GitHub with what you did and what you expected. Please do not attach files that contain personal or confidential information.
