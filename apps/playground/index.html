How an agent edits a file.

An agent never rewrites your file. It proposes a change set against one exact version of the file, your application decides whether to apply it, and the result is checked after it is written. It works with any model, or with no model at all.

  1. Open a sessionon the file's bytes, and ask which operations this file supports.
  2. Plan a change settied to the file's revision and fingerprint.
  3. Validate, preview and diffbefore anything is written.
  4. Approvethe exact change set, from your own trusted review step.
  5. Commitonly if the file has not changed since the plan.
  6. Verifythe written file before anyone downloads it.
const session = await createAgentSession({
  artifact: { kind: 'injoffice.pdf', bytes,
              artifactId: 'report' },
  adapter: createPdfAgentAdapter(),
  actor: { id: 'proposal-agent', kind: 'agent' },
})

const change = await session.plan(
  [{ name: 'pdf.page.rotate',
     input: { pages: [1], degrees: 90 } }],
  { expectedRevision: session.identity.revision,
    expectedFingerprint: session.identity.fingerprint },
)
const { valid } = await change.validate()
const preview = await change.preview()
const diff = await change.diff()

// Later, from your review UI, after a person approves:
const receipt = await change.commit({ idempotencyKey })
if (!receipt.verification.verified) {
  throw new Error('Written, but not verified')
}

What it can change today.

Each engine says which operations a file allows and refuses the rest, rather than guessing.

ExcelCell values and formulas, supported styles, row heights and column widthsInserting sheets, rows or columns, and other structural edits
WordReplacing text in place, run by runRestructuring rich text, editing tracked changes, Word's exact pagination
PowerPointSlide text and shape propertiesInserting or removing imported slides, editing charts, tables and animations
PDFPage operations: rotate, crop, resize, reorder, insert and deleteRewriting text through the agent adapter

Coverage is partial and growing, and this is not Microsoft Office parity. The support page lists every limit.
