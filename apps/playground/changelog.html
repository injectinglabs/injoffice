Changelog

Changes in each InjOffice desktop release, newest first. Every release on GitHub also lists the individual pull requests and publishes SHA256SUMS.

InjOffice 0.1.15

2026-09-23. macOS, Windows and Linux. Release notes and downloads

  • Updates now download in the background; InjOffice asks only whether to restart.
  • The installed app is called InjOffice, without the version number in its name.
  • macOS builds are sealed so Apple Silicon Macs run them. They are still not signed with a Developer ID or notarized.
  • Versions 0.1.13 and 0.1.14 were release candidates for this version and were never published.

InjOffice 0.1.12

2026-09-23. Windows and Linux. Release notes and downloads

  • A maintenance release used to test updating from 0.1.11.

InjOffice 0.1.11

2026-09-22. Windows and Linux. Release notes and downloads

  • The Windows installer is signed.
  • Linux .deb and .rpm updates install from inside the app, with your system asking for administrator approval.

InjOffice 0.1.10

2026-09-22. macOS, Windows and Linux (x64 and ARM64). Release notes and downloads

  • Installers for macOS Apple Silicon and Intel, Windows x64, and Linux x64 and ARM64, with in-app updates on by default.
  • These builds are unsigned and not notarized.
