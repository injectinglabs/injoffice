Choose your system

Every build is the same application. Pick the one that matches your computer.

Before you install

The macOS builds are not signed or notarized yet, so macOS will warn you about an unidentified developer: right-click the app and choose Open the first time. The Windows installer is signed. Windows or your browser may still warn about a new download while the publisher's reputation builds; choose More info → Run anyway.

This is an early release. Core editing works — text, formatting, spreadsheet cells and formulas, slides and PDF annotations — and unsupported operations are disabled with a reason rather than silently doing nothing. Some Office features are still missing.

Checksums for every file are published as SHA256SUMS with each release.

What you get

A familiar editor that keeps your files where they are.

Local by default

Documents are opened, edited and saved on your machine. No account, no upload, no telemetry.

Real Office files

Reads and writes DOCX, XLSX and PPTX directly, preserving the parts of your file it does not change.

Honest about limits

Anything the engine cannot do yet stays visibly disabled, with a plain explanation, instead of failing quietly.

Open source

Apache-2.0 licensed, built in TypeScript and Go. Read the code, file an issue, or build it yourself.
