InjOffice for macOS

A free, open-source editor for Word, Excel, PowerPoint and PDF files that works offline. Documents are opened and saved on your Mac. Nothing is uploaded and there is no account.

Version 0.1.15. macOS 11 Big Sur or newer, Apple Silicon and Intel.

Requirements

macOS11 Big Sur or newer
MacApple Silicon (M1 and later) or Intel
DownloadDisk image (.dmg), about 125 to 130 MB
Price and licenseFree, Apache-2.0

Not sure which Mac you have? Open the Apple menu and choose About This Mac. A Chip line that names Apple M1, M2, M3 or M4 means Apple Silicon; a Processor line that names Intel means Intel.

Install

  1. Download the disk image for your Mac.
  2. Open it and drag InjOffice into Applications.
  3. Open InjOffice from Applications. The first launch needs one extra step, explained below.

First launch

The macOS builds are not signed with an Apple Developer ID and are not notarized yet. They are sealed so Apple Silicon runs them, but macOS still warns that it cannot verify the developer.

  1. In Applications, Control-click (or right-click) InjOffice and choose Open, then Open again.
  2. If macOS only offers Done or Move to Trash, open System Settings, go to Privacy & Security, scroll to the message about InjOffice and choose Open Anyway.

You need to do this once. Later launches open normally.

Updates

InjOffice checks for a new release 15 seconds after it starts and then every six hours. You can turn automatic checks off, or check by hand, in App updates. Updates come only from published InjOffice releases on GitHub.

Because the Mac builds are unsigned, InjOffice cannot replace itself. When a new version is available it opens the matching disk image download; quit InjOffice, drag the new version into Applications to replace the old one, and open it again.

What it opens

InjOffice opens .docx, .docm (macros are not run), .xlsx, .pptx and .pdf files, and imports CSV and TSV. It can also create a blank document, workbook, presentation or PDF. Coverage is growing and is not Microsoft Office parity; the compatibility page lists what each format can change today.

To see how editing works, read Edit Word documents offline and Open and edit XLSX without Excel.

Troubleshooting

macOS says the app cannot be opened

Use Open Anyway in System Settings, Privacy & Security, as described under First launch. The warning is about the missing Developer ID, not about damage to the file.

Check that the download is complete

Compare the file's hash with the SHA256SUMS file published with the release:

shasum -a 256 InjOffice-0.1.15-mac-arm64.dmg

A document will not open

InjOffice explains why: password-protected files have to be unprotected in the app that created them, and older binary formats (.doc, .xls, .ppt, .xlsb) and OpenDocument files are not opened, so their bytes are never rewritten.

Uninstall

Quit InjOffice and move it from Applications to the Trash. Your documents stay wherever you saved them.
