InjOffice for Linux

An open-source editor for Word, Excel, PowerPoint and PDF files, packaged as an AppImage, a .deb and an .rpm. It works offline: nothing is uploaded and there is no account.

Version 0.1.15. x86_64. Install-tested in CI on Ubuntu 22.04 and 24.04.

Which package

PackageUse it for
AppImageAny distribution; one file, no installation
.debUbuntu, Debian and their derivatives
.rpmFedora, RHEL and other RPM-based distributions

Current releases are built for x86_64 (Intel and AMD). Run dpkg --print-architecture on Debian or Ubuntu: amd64 needs these packages. ARM64 packages were last published with version 0.1.10 and are listed on the 0.1.10 release.

For every change to the desktop app, CI installs the .deb and starts InjOffice on Ubuntu 22.04 and 24.04. Other distributions, desktops and GPUs are not certified.

Install

AppImage

chmod +x InjOffice-0.1.15-linux-x86_64.AppImage
./InjOffice-0.1.15-linux-x86_64.AppImage

If it does not start on a recent Ubuntu, install FUSE 2 support (libfuse2t64 on 24.04, libfuse2 on 22.04), which AppImages need.

Debian and Ubuntu

sudo apt install ./InjOffice-0.1.15-linux-amd64.deb

Fedora and RHEL

sudo dnf install ./InjOffice-0.1.15-linux-x86_64.rpm

The packages add an InjOffice launcher with its icon to your applications menu.

Updates

InjOffice checks for a new release 15 seconds after it starts and then every six hours. You can turn automatic checks off, or check by hand, in App updates. Updates come only from published InjOffice releases on GitHub.

  • AppImage: the update downloads in the background, and InjOffice asks whether to restart into it.
  • .deb and .rpm: the update also downloads in the background. When you restart to install it, your system asks for administrator approval, because the package manager installs it.

Your open documents are checked before InjOffice restarts, and you can keep working and update later.

What it opens

InjOffice opens .docx, .docm (macros are not run), .xlsx, .pptx and .pdf files, and imports CSV and TSV. It can also create a blank document, workbook, presentation or PDF. Coverage is growing; the compatibility page lists what each format can change today.

Troubleshooting

Ubuntu App Center calls the package unknown or potentially unsafe

A downloaded .deb is shown that way: App Center does not load a local package's icon or publisher. There is no APT or YUM repository or store listing for InjOffice yet, so installing the file with apt as above is the straightforward route.

Check that the download is complete

sha256sum InjOffice-0.1.15-linux-amd64.deb

Compare the result with the SHA256SUMS file published with the release.

A document will not open

InjOffice explains why: password-protected files have to be unprotected in the app that created them, and older binary formats (.doc, .xls, .ppt, .xlsb) and OpenDocument files are not opened, so their bytes are never rewritten.

Uninstall

Delete the AppImage file, or remove the package with the same package manager you installed it with. Your documents stay wherever you saved them.
