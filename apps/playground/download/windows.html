InjOffice for Windows

Free, open-source office software for Word, Excel, PowerPoint and PDF files. It works offline: documents are opened and saved on your PC, nothing is uploaded, and there is no account.

Version 0.1.15. Windows 10 and 11, 64-bit. Signed installer.

Requirements

WindowsWindows 10 or Windows 11, 64-bit (x64)
DownloadInstaller (.exe), about 107 MB
SignatureCode-signed through Microsoft's Artifact Signing service
Price and licenseFree, Apache-2.0

There is no separate build for Windows on Arm.

Install

  1. Download the installer.
  2. Run it. It installs InjOffice for your Windows user account and opens it when it finishes.
  3. Find InjOffice in the Start menu afterwards.

If Windows or your browser warns you

The installer is signed, but Microsoft SmartScreen and browsers also look at how often a publisher's files have been downloaded. A new publisher has little of that reputation yet, so you may see a warning even though the signature is valid.

  • Windows protected your PC: choose More info, check the publisher, then Run anyway.
  • Edge says the file is not commonly downloaded: open the download's menu, choose Keep, then confirm.

To check the signature yourself, right-click the installer, choose Properties and open Digital Signatures.

Updates

InjOffice checks for a new release 15 seconds after it starts and then every six hours. You can turn automatic checks off, or check by hand, in App updates. Updates come only from published InjOffice releases on GitHub.

On Windows the update downloads in the background. When it is ready, InjOffice asks whether to restart; your open documents are checked before it restarts, and you can keep working and update later.

What it opens

InjOffice opens .docx, .docm (macros are not run), .xlsx, .pptx and .pdf files, and imports CSV and TSV. It can also create a blank document, workbook, presentation or PDF. Coverage is growing and is not Microsoft Office parity; the compatibility page lists what each format can change today.

See Edit Word documents offline and Open and edit XLSX without Excel for the workflows.

Troubleshooting

Check that the download is complete

In PowerShell, compare the hash with the SHA256SUMS file published with the release:

Get-FileHash .\InjOffice-0.1.15-win-x64.exe -Algorithm SHA256

A document will not open

InjOffice explains why: password-protected files have to be unprotected in the app that created them, and older binary formats (.doc, .xls, .ppt, .xlsb) and OpenDocument files are not opened, so their bytes are never rewritten.

Uninstall

Open Settings, Apps, Installed apps, find InjOffice and choose Uninstall. Your documents stay wherever you saved them.
